VILL3N — وصل‌کردن این سایت به «کنترول سنتر» (سرور خانگی)
================================================================

این سایت یک برنامهٔ Node.js است؛ یک پوشهٔ HTML ساده نیست.
پس در کنترول سنتر آن را «برنامه / سرویس» ثبت کنید، نه «پوشهٔ فایل».

مقدارهایی که کنترول سنتر می‌پرسد
--------------------------------
نام            : VILL3N
پوشه           : D:\HomeServer\Sites\vill3n-top
نوع            : Node.js  (بدون npm install، بدون build)
فرمان اجرا     : node server.js
                 (اگر Node نصب نیست: START.bat خودش یک نسخه می‌گیرد)
درگاه (Port)   : 4780
آدرس داخلی     : http://127.0.0.1:4780
دامنه          : vill3n.top   (و www.vill3n.top اگر می‌خواهید)
                 ⚠️ admin.vill3n.top و api.vill3n.top را به این سایت ندهید:
                 آن دو مالِ خودِ کنترول سنتر (برنامهٔ مدیر و سرورِ حساب) هستند.
بررسی سلامت    : http://127.0.0.1:4780/healthz
پنل مالک       : http://127.0.0.1:4780/admin
پشتیبان‌گیری از : پوشهٔ data  (همهٔ اطلاعات سایت همین‌جاست)

همین مقدارها در فایل site.json هم هست و کنترول سنتر (از نسخهٔ 1.50.44)
پورت 4780، دامنه و فرمانِ اجرا را خودش از آن می‌خواند.
بعد از افزودن، «اجرای خودکار هنگام بالا آمدن پنل» را روشن و یک بار «اجرا» را بزنید.
اگر INSTALL-SERVICE.bat را هم نصب کرده‌اید، یکی را بردارید: دو نسخه با هم بالا نمی‌آیند.

اگر کنترول سنتر جای ثبت «برنامه» ندارد
--------------------------------------
۱) INSTALL-SERVICE.bat را یک بار دوبار-کلیک کنید
   → سایت با هر بار روشن‌شدن ویندوز خودش بالا می‌آید.
۲) در کنترول سنتر (یا Cloudflare Tunnel) دامنهٔ vill3n.top را
   به http://127.0.0.1:4780 وصل کنید.

بعد از وصل‌شدن دامنه
--------------------
۱) پنل مالک → «تنظیمات» → «نشانی سایت» را https://vill3n.top بگذارید.
۲) پنل مالک → «اتصال و استقرار» → دکمهٔ «بررسی اتصال دامنه» را بزنید.
برای Cloudflare Tunnel لازم نیست config.json را دست بزنید.
راهنمای کامل: docs\راهنما.md

به‌روزرسانی از کنترول سنتر (از نسخهٔ 2.1.0)
--------------------------------------------
سایت به‌روزرسانی را فقط از همین سرورِ خانگی می‌گیرد، نه از اینترنت:
کنترول سنتر نسخهٔ تازه را می‌گیرد و می‌سنجد، و سایت دو دقیقه بعد از روشن شدن
و بعد هر ساعت از آن می‌پرسد. هر فایل با هشِ sha256 سنجیده می‌شود، نصب می‌شود
و سایت خودش دوباره بالا می‌آید. پوشهٔ data و config.json هرگز دست نمی‌خورند.
شرط: سایت از داخلِ کنترول سنتر اجرا شود (نه START.bat یا سرویسِ ویندوز).
به‌روزرسانیِ دستی:  node server.js update   (وقتی سایت از کنترول سنتر اجرا شده)
خاموش کردن:        در config.json بنویسید  "autoUpdate": false
