# توحید — نسخهٔ بومی اندروید

بازنویسی کامل با **Kotlin + Jetpack Compose**. بدون HTML، بدون WebView،
بدون هیچ چیزی که به وب ربط داشته باشد.

> **این نسخه در حال ساخت است.** مرحله‌به‌مرحله کامل می‌شود و هر مرحله از
> داخلِ خودِ برنامه به‌روزرسانی می‌گیرد — لازم نیست برای هر تغییر سراغ
> Android Studio بروید.

---

## داده‌های شما نمی‌پرد

نسخهٔ بومی **همان فایل داده** را می‌خواند و می‌نویسد که نسخهٔ وب می‌نوشت —
همان ۱۸ مجموعه با همان نام فیلدها. یعنی:

- بارِ اول که باز شود، دفترِ دکان را از نسخهٔ قبلی می‌آورد (خودکار)
- فایلِ پشتیبان بین دو نسخه یکی است

اگر نسخهٔ بومی را روی نسخهٔ قبلی نصب کنید، همان بستهٔ برنامه و همان امضاست،
پس داده سرِ جایش می‌ماند و خوانده می‌شود.

## محاسبه‌ها عیناً همان‌اند

فرمول‌ها از خودِ نسخهٔ وب برداشته شده‌اند، نه از روی حدس:

```
موجودی      = مجموع ورودی انبار − مقدار فروخته‌شده
فروخته‌شده  = اقلام فروش (بدون فروش‌های لغوشده) − مقدار مرجوعی
بدهی مشتری  = مجموع «داده» − مجموع «گرفته»
بدهی به تأمین‌کننده = مجموع بدهی خریدها − مجموع پرداخت‌ها
```

جاهایی که می‌شد «بهترش» کرد هم عمداً دست نخورده: عددی که فروشنده روی کاغذ
دارد نباید با به‌روزرسانی عوض شود.

---

## به‌روزرسانی از گیت‌هاب

**بیشتر** → **به‌روزرسانی از گیت‌هاب** → مخزن را بنویسید → **بررسی**.

مخزن قابل تغییر است، پس هر وقت خواستید از جای دیگری به‌روزرسانی بگیرید،
همان‌جا عوضش کنید.

---

## ساخت

روی GitHub خودکار ساخته می‌شود (Actions → «توحید بومی»)، و APK زیر برچسب
`tohid-native` منتشر می‌شود.

دستی:

```bash
cd homelab-panel/tohid-native
gradle assembleRelease
```

نیازمند Android SDK و Java 17.
