# برنامهٔ سرور خانگی (پنجرهٔ ویندوزی)

نسخهٔ **1.1.3**

یک برنامهٔ ویندوزیِ واقعی برای کارهای روزمرهٔ سرور — نه مرورگر، نه WebView.
با WinForms ساخته شده، یعنی همان دکمه‌ها و کادرهای خودِ ویندوز؛ هیچ چیزی هم
لازم نیست نصب شود (PowerShell از خودِ ویندوز است).

## نصب

در ریشهٔ پروژه روی **`نصب-برنامه.bat`** دوبار کلیک کنید. یک نصب‌کنندهٔ معمولی
باز می‌شود:

1. **خوش‌آمد** — می‌گوید برنامه چه کار می‌کند
2. **انتخابِ پوشه** — پیش‌فرض `C:\Users\<شما>\PumpServer`؛ با دکمهٔ «انتخابِ پوشه»
   هر جای دیگری هم می‌شود. گزینه‌ها: میان‌برِ دسکتاپ، منوی استارت،
   نصبِ وابستگی‌ها، و اجرای برنامه بعد از نصب
3. **نصب** — فایل‌ها کپی می‌شوند و خروجیِ `npm install` **داخلِ خودِ پنجره**
   دیده می‌شود (نه در پنجرهٔ سیاه)
4. **پایان**

اگر همان پوشه‌ای را بدهید که قبلاً نصب کرده‌اید، به‌روزرسانی می‌شود و پوشهٔ
`data` و فایل `.env` دست نمی‌خورند.

بعد از نصب، از **میان‌برِ روی دسکتاپ** بازش کنید — آن راه اصلاً پنجرهٔ سیاه ندارد.

## هیچ ترمینالی باز نمی‌شود

سرور بدونِ هیچ پنجره‌ای اجرا می‌شود و همهٔ خروجی‌اش در تبِ **«ترمینالِ سرور»**
داخلِ خودِ برنامه، زنده دیده می‌شود — همان چیزی که قبلاً در پنجرهٔ سیاه بود.
با دکمهٔ «روشن کردنِ سرور» خودش همان تب را باز می‌کند تا ببینید چه خبر است.

## چه کار می‌کند

| تب | کار |
|----|-----|
| آدرسِ سرور | آدرسی که باید در اپِ اندروید/ویندوز/سایت بگذارید — خانگی و اینترنتی، با دکمهٔ کپی |
| تستِ ورود با کد | شماره یا ایمیل بزنید، کد بگیرید، تأیید کنید — همه از داخلِ همین پنجره |
| پیامک و ایمیل | تنظیماتِ جی‌میل و سرویسِ پیامک؛ ذخیره که کنید، خودش سرور را دوباره بالا می‌آورد |
| برنامه‌ها و سایت‌ها | هر برنامه/سایت با شناسه، کلید و **آدرسِ API اختصاصیِ خودش**؛ ساختن، خاموش کردن، کلیدِ تازه، و کپیِ یک‌جای آدرس‌ها |
| کدِ برنامه‌ها | کدِ آمادهٔ Kotlin / فلاتر / C# / جاوااسکریپت / curl با دکمهٔ کپی |
| ترمینالِ سرور | خروجیِ زندهٔ سرور؛ اگر پیامک تنظیم نشده باشد، کدِ ورود همین‌جا نوشته می‌شود |
| به‌روزرسانی | نسخهٔ تازه را از GitHub می‌گیرد و خودش نصب می‌کند |

بالای پنجره همیشه معلوم است سرور روشن است یا خاموش، و با یک دکمه عوض می‌شود.

## برنامه‌ها و سایت‌ها

تبِ «برنامه‌ها و سایت‌ها» دفترِ همهٔ برنامه‌هایی است که به این سرور وصل می‌شوند.
هر کدام:

* **شناسه** (`shop`, `pump`, …) — کاربرانش از بقیه جداست
* **کلیدِ اختصاصی** (`hlp_…`) — با تیکِ «بدونِ کلید کار نکند» اجباری می‌شود
* **متنِ پیامکِ خودش** و **طولِ کدِ خودش** (مثلاً فروشگاه ۵ رقمی، پمپ ۶ رقمی)
* دکمهٔ **روشن/خاموش** — یک برنامه را می‌بندید بی‌آنکه بقیه بخوابند

پایینِ همان تب، **کارتِ آدرسِ API** آن برنامه آماده است: آدرسِ فرستادنِ کد،
تأییدِ کد، و نمونهٔ بدنهٔ درخواست با شناسه و کلیدِ خودش. دکمهٔ «کپیِ آدرس‌های API»
همه را یک‌جا کپی می‌کند تا بدهید به سازندهٔ آن برنامه.

برنامه‌ای که بدونِ ثبتِ قبلی کد بخواهد، خودش این‌جا ثبت می‌شود — پس هیچ‌کس
پشتِ در نمی‌ماند و شما بعداً می‌بینیدش.

> این تب از راهِ «کلیدِ محلی» کار می‌کند: سرور یک کلیدِ تصادفی در
> `data/local-admin.key` می‌گذارد که فقط برنامه‌های رویِ همین کامپیوتر می‌توانند
> بخوانند. برای همین لازم نیست هر بار نامِ کاربری و رمزِ پنل بزنید، و در عینِ
> حال هیچ سایتی در مرورگر نمی‌تواند جای شما این کارها را بکند.

## به‌روزرسانی از داخلِ برنامه

تبِ «به‌روزرسانی» → «بررسیِ نسخهٔ تازه» → اگر نسخهٔ جدیدی بود، «به‌روزرسانی کن».

برنامه **خودش هم** هر بار که باز می‌شود بررسی می‌کند؛ اگر نسخهٔ تازه‌ای باشد،
بالای پنجره خبر می‌دهد و کنارِ نامِ تب یک نقطه می‌گذارد. (این را می‌شود خاموش کرد.)

نامِ شاخه یادش می‌ماند — یک بار بنویسید، دفعهٔ بعد خودش همان را می‌زند.

ترتیبِ کار:

1. از کدِ فعلی پشتیبان می‌گیرد → `homelab-panel\server\data\backups\code-<تاریخ>`
   (سه پشتیبانِ آخر می‌ماند، قدیمی‌ترها خودشان پاک می‌شوند)
2. نسخهٔ تازه را از GitHub می‌گیرد و باز می‌کند
3. سرور را خاموش می‌کند، فایل‌ها را عوض می‌کند، `npm install` می‌زند
4. سرور را دوباره روشن می‌کند

**هرگز پاک نمی‌شود:** پوشهٔ `data` (دیتابیس، کاربران، لاگ) و فایل `.env` (رمزها).

فیلدِ «شاخه» به‌صورت پیش‌فرض `main` است. اگر تغییرات هنوز در شاخهٔ دیگری است،
نامِ همان شاخه را بنویسید.

## فایل‌ها

| فایل | چیست |
|------|------|
| `..\..\نصب-برنامه.bat` | نصب‌کننده (در ریشهٔ پروژه) |
| `install.ps1` | پنجرهٔ نصب |
| `برنامه-سرور.bat` | اجرای برنامه بدونِ نصب |
| `launch.vbs` | همان اجرا، ولی بدونِ حتی یک لحظه پنجرهٔ سیاه (میان‌برها به این وصل‌اند) |
| `app.ps1` | خودِ پنجرهٔ برنامه (WinForms) |
| `lib.ps1` | مغزِ کار: .env، روشن/خاموش، ترمینال، API، به‌روزرسانی، نصب |
| `عیب‌یابی.bat` | اجرای برنامه با نمایشِ خطاها |
| `test/lib.tests.ps1` | آزمونِ مغز — بدونِ باز شدنِ پنجره |

اجرای آزمون:

```
powershell -NoProfile -ExecutionPolicy Bypass -File test\lib.tests.ps1
```

## اگر باز نشد (یا باز شد و گم شد)

برنامه بدونِ پنجرهٔ سیاه اجرا می‌شود، پس خطاها جایی دیده نمی‌شدند. حالا:

* هر خطا در `homelab-panel\server\data\desktop-error.log` نوشته می‌شود
* اگر پنجره بی‌درنگ بسته شود، خودش یک پیام نشان می‌دهد و مسیرِ گزارش را می‌گوید
* اگر بخشی از برنامه بالا نیاید، بقیه کار می‌کند و بالای پنجره می‌نویسد کدام بخش

برای دیدنِ زندهٔ خطا:

| مشکل | فایلی که باید بزنید |
|------|---------------------|
| نصب‌کننده باز نمی‌شود | `اگر-باز-نشد.bat` (در ریشهٔ پروژه) |
| خودِ برنامه باز نمی‌شود | `عیب‌یابی.bat` (کنارِ `app.ps1`) |

هر دو با پنجرهٔ سیاه و بدونِ مخفی‌کاری اجرا می‌کنند و آخرش می‌ایستند تا خطا را
بخوانید یا از آن عکس بگیرید.

* **می‌گوید اجرای اسکریپت ممنوع است:** خودِ `برنامه-سرور.bat` و میان‌برها این را
  دور می‌زنند (`-ExecutionPolicy Bypass`)؛ از همان‌ها بازش کنید.
* **سرور روشن نمی‌شود:** Node.js نصب است؟ تبِ «ترمینالِ سرور» علتش را می‌گوید.

لینوکس ندارد؛ آن‌جا همان صفحهٔ `http://localhost:4700/connect` را باز کنید.
