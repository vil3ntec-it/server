# برنامهٔ ویندوز — مرکز فرمان

همان پنلِ داخلِ همین مخزن، فقط داخلِ یک پنجرهٔ واقعیِ ویندوز:

```
┌────────────────────────────────────────────────────────┐
│ ● مرکز فرمان   آماده · http://127.0.0.1:4700   [دکمه‌ها] │
├────────────────────────────────────────────────────────┤
│                                                         │
│                   خودِ پنل                              │
│                   (تمامِ صفحه — ترمینال بسته است)        │
│                                                         │
└────────────────────────────────────────────────────────┘
```

با زدنِ دکمهٔ **ترمینال** کادرِ خودش پایین باز می‌شود:

```
├──────────────── ▬▬▬ ────────────────────────────────────┤  ← دستگیره
│ ترمینال — خروجی واقعی سرور  [کپی] [پاک] [پنجرهٔ جدا ⧉] [✕]│
│ 08:20:55  ✅ پنل مدیریت سرور خانگی بالا آمد             │
│ 08:20:55  پوشهٔ داده: D:\ControlCenter                  │
└────────────────────────────────────────────────────────┘
```

- آیکن روی دسکتاپ و در منوی Start
- بارِ اول می‌پرسد **اطلاعات کجا ذخیره شود** و نقشهٔ پوشه‌ها را نشان می‌دهد
- ترمینال، خروجیِ واقعیِ سرور است — نه چیزِ تزئینی
- **به نصبِ Node.js نیاز ندارد**؛ Node همراهِ خودِ برنامه می‌آید

### ترمینال مزاحمِ صفحه نمی‌شود

| کار | چطور |
| --- | --- |
| باز و بسته کردن | دکمهٔ **ترمینال** در نوارِ بالا، یا **✕** در خودِ کادر |
| کم و زیاد کردنِ بلندی | **دستگیرهٔ** بالای کادر را با ماوس بکش |
| بردن به پنجرهٔ جداگانه | **پنجرهٔ جدا ⧉** — پنجره‌اش تمام‌صفحه باز می‌شود |
| تمام‌صفحهٔ واقعی | در آن پنجره: دکمهٔ **تمام‌صفحه** یا کلیدِ **F11** |
| برگرداندن به برنامه | در آن پنجره: **برگشت به برنامه** یا کلیدِ **Esc** |

- اولِ کار ترمینال **بسته** است تا کلِ پنجره مالِ خودِ پنل باشد
- انتخابِ شما (باز/بسته و بلندی) یادش می‌ماند و دفعهٔ بعد همان‌طور بالا می‌آید
- اگر سرور بالا نیامد، ترمینال خودش باز می‌شود تا دلیلش را ببینید
- پنجرهٔ جدا همان خروجیِ **زنده** را می‌گیرد، نه یک کپیِ ثابت

## گرفتنِ فایلِ نصبی

**راهِ ساده:** از بخشِ [Releases](https://github.com/vil3ntec-it/server/releases) فایل
`ControlCenter-Setup-<نسخه>.exe` را بگیر و اجرا کن. موقعِ نصب می‌پرسد
**کجا نصب شود**.

**اگر هنوز Release نساخته‌ای:** در GitHub → زبانهٔ **Actions** → آخرین اجرای
«برنامه ویندوز» → پایینِ صفحه، بخشِ **Artifacts** → `ControlCenter-Setup`.

این گردشِ کار خودش با هر تغییرِ برنامه اجرا می‌شود، پس معمولاً یک فایلِ تازه
آنجا هست. برای ساختنِ Release هم کافی است یک تگ بزنی:

```bash
git tag v1.1.0 && git push origin v1.1.0
```

## اجرا از روی کد (برای توسعه)

```bash
cd homelab-panel/server && npm install          # وابستگی‌های سرور
cd ../web && npm install && npm run build       # ساختِ رابط کاربری
cd ../desktop && npm install && npm start       # اجرای برنامه
```

## ساختِ فایلِ نصبی روی ویندوزِ خودت

```powershell
cd homelab-panel\desktop
npm install
npm run build:win
```

خروجی در `desktop\dist\ControlCenter-Setup-<نسخه>.exe`.

## آزمون

```bash
cd homelab-panel/desktop && npm test
```

برنامه واقعاً بالا می‌آید، پوشه انتخاب می‌شود، سرور اجرا می‌شود و بررسی
می‌شود که ترمینال خروجیِ واقعی دارد و پنل داخلِ پنجره بار شده.

## اطلاعات کجا می‌رود؟

هرجا که بارِ اول انتخاب کنی. پیش‌فرضِ پیشنهادی `Documents\ControlCenter` است.
هر وقت خواستی ببینی‌اش، دکمهٔ **پوشهٔ اطلاعات** در نوارِ بالا آن را باز می‌کند.

```
<پوشهٔ انتخابی>\
├── panel.db          دیتابیس پنل
├── Projects\         پوشهٔ هر پروژه
│   └── <نام پروژه>\
│       ├── app\  config\  data\
│       ├── backups\    بکاپ‌ها
│       ├── logs\       لاگ‌ها
│       └── releases\   فایل‌های منتشرشده
├── vault.key         کلید گاوصندوق — با اولین راز ساخته می‌شود
└── updates\          بستهٔ به‌روزرسانی‌ها
```

> ⚠️ از `vault.key` بکاپ بگیر. بدونِ آن، رازهای گاوصندوق باز نمی‌شوند.

**جای نصبِ خودِ برنامه** (کدها) با **جای اطلاعات** یکی نیست — و همین خوب است:
با حذف یا به‌روزرسانیِ برنامه، اطلاعاتت دست نمی‌خورد.

## چطور کار می‌کند

| بخش | چه می‌کند |
| --- | --- |
| `main.js` | سرور را با Node ی که همراهِ Electron است اجرا می‌کند، خروجی‌اش را می‌گیرد، منتظرِ `/health` می‌ماند و بعد پنجره را به پنل وصل می‌کند |
| `preload.cjs` | پلِ امن؛ فقط همان چند کارِ لازم از رابط کاربری قابلِ صدا زدن است |
| `shell.html/css/js` | نوارِ بالا، صفحهٔ بارِ اول، و کادرِ ترمینال |
| `terminal.html/js` | ترمینال وقتی در پنجرهٔ خودش باز می‌شود؛ همان جریانِ زندهٔ لاگ را می‌گیرد |

نکته‌های امنیتی: `contextIsolation` روشن، `nodeIntegration` خاموش، CSP سخت‌گیرانه
روی خودِ پوسته، و پیوندهای بیرونی در مرورگرِ سیستم باز می‌شوند نه داخلِ برنامه.
