# سرورِ خانگیِ پمپ یعقوبی

نسخهٔ برنامه: **2.9.316**

این مخزن دو بخش دارد که باید **کنارِ هم** بمانند؛ پنل، دستیار را از همین‌جا پیدا می‌کند:

| پوشه | چیست |
| --- | --- |
| `homelab-panel/` | پنلِ مدیریتِ سرورِ خانگی (Express + Socket.IO + SQLite) به‌همراه رابط کاربریِ ساخته‌شده در `server/public` |
| `ai-support/` | دستیارِ پشتیبانیِ هوشمند — فقط‌خواندنی، بدون وابستگیِ npm |

راهنمای گام‌به‌گامِ راه‌اندازی در فایل [`از-اینجا-شروع-کنید.txt`](از-اینجا-شروع-کنید.txt) است،
و راهنمای وصل کردنِ برنامه‌ها (اپِ اندروید، برنامهٔ ویندوز، سایت‌ها) در
[`اتصال-برنامه-ها.txt`](اتصال-برنامه-ها.txt).

## راه‌اندازیِ سریع

پیش‌نیاز: Node.js نسخهٔ ۲۲ به بالا

**ویندوز — همه‌چیز یک‌جا:** داخل پوشهٔ `homelab-panel` روی `نصب-همه-چیز.bat` دوبار کلیک کن.
وابستگی‌ها، Ollama، مدلِ مناسبِ همان کامپیوتر و ایندکسِ دانش را خودش می‌گیرد و بعد پنل را بالا می‌آورد
(حدود ۳ گیگابایت دانلود، فقط بارِ اول). دفعه‌های بعد `homelab-panel\server\start-windows.bat`.

**لینوکس:**

```bash
cd homelab-panel/server
npm install
bash start-linux.sh
```

برای نصب یا به‌روزرسانیِ «مغز» به‌تنهایی: `bash ai-support/نصب-مغز.sh` (ویندوز: `نصب-مغز.bat`).

دستیار خودش با پنل بالا می‌آید (پورت محلیِ 8788) و سایت از راهِ `/ai/support` به آن می‌رسد.
پنل روی پورت `4700` است؛ برای دیدنِ نسخهٔ در حالِ اجرا: `http://localhost:4700/health`

## وصل کردنِ برنامه‌ها (اندروید / ویندوز / سایت)

سرور را روشن کنید و این آدرس را باز کنید:

```
http://localhost:4700/connect
```

آن صفحه سه چیز می‌دهد: آدرسی که باید در برنامه بگذارید، دکمهٔ تستِ زندهٔ
«ورود با کدِ شش‌رقمی»، و کدِ آمادهٔ اندروید/فلاتر/ویندوز/جاوااسکریپت.

ورودِ کاربرانِ برنامه‌ها با شمارهٔ موبایل یا ایمیل و کدِ شش‌رقمی انجام می‌شود —
بدونِ ثبت‌نام و بدونِ رمز عبور:

```
POST /api/app/auth/request-code   {"phone":"09121234567"}   # یا {"email":"a@gmail.com"}
POST /api/app/auth/verify-code    {"phone":"09121234567","code":"123456"}
→ {"ok":true,"token":"…"}          # بعد از این:  Authorization: Bearer <token>
```

برای این‌که کد واقعاً پیامک/ایمیل شود، در `homelab-panel/server/.env` سرویسِ
پیامک یا SMTP (جی‌میل) را بگذارید — نمونه‌ها در `.env.example` هستند. تا وقتی
تنظیم نشده، سرور کد را در «پنل ← لاگ‌ها» می‌نویسد تا بتوانید تست کنید.

راهنمای کاملِ فارسی: [`اتصال-برنامه-ها.txt`](اتصال-برنامه-ها.txt)
