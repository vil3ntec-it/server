  سرورِ خانگیِ پمپ یعقوبی + دستیارِ پشتیبانیِ هوشمند
  نسخهٔ برنامه: 2.9.316
═══════════════════════════════════════════════════════════════════════════

داخلِ این پوشه دو چیز است:

  homelab-panel/   پنلِ مدیریتِ سرورِ خانگی (همان که داشتی)
  ai-support/      دستیارِ هوشِ مصنوعی (تازه)

⚠️ این دو پوشه باید **کنارِ هم** بمانند. پنل، دستیار را از همین‌جا پیدا می‌کند.
   اگر جدایشان کنی، دستیار بالا نمی‌آید.


───────────────────────────────────────────────────────────────────────────
  ۱) راه‌اندازی — یک بار
───────────────────────────────────────────────────────────────────────────

پیش‌نیاز: Node.js نسخهٔ ۲۲ به بالا  →  https://nodejs.org

ویندوز:
    وارد پوشهٔ  homelab-panel\server  شو
    فایل  start-windows.bat  را دوبار کلیک کن
    (بار اول خودش npm install را انجام می‌دهد و کمی طول می‌کشد)

لینوکس:
    cd homelab-panel/server
    npm install
    bash start-linux.sh

دستیار **خودش** با پنل بالا می‌آید. کارِ جداگانه‌ای ندارد.
اگر این خط را در پنجرهٔ سیاه دیدی، یعنی درست کار می‌کند:

    🤖 دستیارِ پشتیبانی روشن شد (پورت 8788) — سایت از راهِ /ai/support به آن می‌رسد


───────────────────────────────────────────────────────────────────────────
  ۲) آزمایش
───────────────────────────────────────────────────────────────────────────

سایت را باز کن  →  رباتِ دستیار  →  تبِ «پشتیبانی هوشمند»
بپرس: «میانبرهای برنامه چیست؟»

اگر جواب آمد، همه‌چیز وصل است.

هیچ تنظیمی در مرورگر لازم نیست. سایت با همان آدرسی که برای همگام‌سازی
استفاده می‌کند به دستیار هم می‌رسد.


───────────────────────────────────────────────────────────────────────────
  ۳) روشن کردنِ «مغز» — اختیاری ولی مهم
───────────────────────────────────────────────────────────────────────────

بدونِ این مرحله، دستیار کار می‌کند ولی جواب‌هایش فقط متنِ مستندات است و
کنارِ جواب می‌نویسد «از مستندات». برای اینکه واقعاً بفهمد و جمله بسازد:

  گامِ ۱ — Ollama را نصب کن:   https://ollama.com/download

  گامِ ۲ — ببین کامپیوترت چه مدلی را می‌کِشد:

      cd ai-support
      node bin/detect-hardware.mjs

      (اسمِ مدلِ مناسب را خودش می‌گوید — از رویش کپی کن)

  گامِ ۳ — مدل را بگیر:

      ollama pull <همان اسمی که گفت>
      ollama pull nomic-embed-text

  گامِ ۴ — تنظیم و ساختِ ایندکس:

      node bin/detect-hardware.mjs --apply
      node bin/build-index.mjs

  گامِ ۵ — پنل را یک بار ببند و دوباره باز کن.

از این به بعد کنارِ جواب‌ها دیگر «از مستندات» نمی‌نویسد.


───────────────────────────────────────────────────────────────────────────
  ۴) نگرانِ کند شدنِ کامپیوتر نباش
───────────────────────────────────────────────────────────────────────────

دستیار پنج ترمز دارد:

  • هر لحظه فقط یک سؤال پردازش می‌شود
  • سؤالِ تکراری اصلاً به مدل نمی‌رسد (کش)
  • وقتی چند دقیقه بیکار بماند، مدل از رَم بیرون می‌رود
  • اگر کامپیوتر مشغولِ کارِ دیگری باشد، خودش به حالتِ ساده می‌افتد
  • صفِ سؤال‌ها سقف دارد

بدترین حالتِ ممکن «جوابِ ساده‌تر» است، نه «کامپیوترِ قفل‌شده».

اگر کامپیوترت ضعیف است، در فایلِ  homelab-panel/server/.env  این را بگذار:

    HLP_AI_MODEL=qwen2.5:1.5b-instruct-q4_K_M

و برای خاموش کردنِ کاملِ دستیار:

    HLP_AI_ENABLED=0


───────────────────────────────────────────────────────────────────────────
  ۵) چیزی که دستیار می‌تواند و نمی‌تواند
───────────────────────────────────────────────────────────────────────────

می‌تواند:
  • راهنماییِ کارِ با برنامه، میانبرها، مشکلاتِ رایج
  • خواندنِ اعدادِ واقعیِ حساب‌ها (الباقی، بردگی، رسید، باقیِ مخزن، قرضِ کل)
  • جست‌وجو در همهٔ بخش‌ها (فقط برای مدیر)
  • ساختِ QR برای لینک‌های رسمی

نمی‌تواند — و ابزارش اصلاً وجود ندارد:
  • هیچ چیزی را بسازد، عوض کند یا پاک کند
  • حساب بسازد یا حذف کند یا رمز عوض کند
  • تنظیمات، فونت، رنگ یا ظاهرِ برنامه را دست بزند
  • رمز یا توکن نشان بدهد
  • دستورِ سیستم‌عامل اجرا کند

اعدادِ حساب‌ها روی **خودِ دستگاهِ کاربر** حساب می‌شوند و از آن بیرون نمی‌روند.
